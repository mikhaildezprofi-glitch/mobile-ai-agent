## Уже реализовано в исходниках

- Локальный llama.cpp runtime и загрузка GGUF из пользовательского хранилища приложения; предусмотрено восстановление Qwen3 из приватной папки models.
- Гибридный координатор LOCAL/HYBRID: текст, код и сложные запросы могут направляться в Gemini API; изображения, файлы, текущая информация и Android-действия не отправляются в облако автоматически.
- Gemini API key хранится зашифрованным через Android Keystore.
- Добавлена явная проверка Gemini API: короткий generateContent запрос проверяет ключ, права проекта и доступность модели. Она запускается только по нажатию в настройках.
- Установленное приложение Gemini можно открыть или передать текущий текст через Android Sharesheet. Пользователь сам выбирает получателя.
- Есть локальный путь обработки изображений/видеокадров при наличии совместимой vision-модели и projector.
- Вложения и история чатов сохраняются в приложении; фоновая генерация использует foreground service.
- CI теперь должен запускать unit tests маршрутизации до сборки APK.

## Не считать завершённым

- Успешный APK build не доказывает запуск нативных библиотек и inference на реальном телефоне.
- Gemini API не проверен реальным ключом на устройстве.
- Gemini Sharesheet handoff не является Gemini Live API и не обеспечивает автоматический обмен ответами.
- Поиск в интернете и выполнение Android-команд пока не подключены как реальные инструменты; координатор сообщает об ограничении вместо имитации выполнения.
- Голосовой wake-word «Джимми», непрерывный диалог после активации, автоматический возврат в ожидание и отдельная speaker verification ещё не реализованы.
- TTS-ответы и полноценная фоновая голосовая сессия требуют отдельной реализации и runtime-проверки.

## Следующие этапы по приоритету

### 1. CI и релиз 0.4.1

- Убедиться, что новый GitLab SHA синхронизирован с GitHub.
- Убедиться, что все AgentCoordinator unit tests прошли.
- Убедиться, что APK build, metadata, checksum и Release созданы для одного и того же SHA.
- Сохранить APK и метаданные как проверенный артефакт.

### 2. Runtime на Samsung S23 FE

- Установить APK поверх текущей версии только после проверки подписи.
- Проверить запуск приложения и JNI без ошибки `__kmpc_global_thread_num`.
- Проверить загрузку `Qwen3-1.7B-Q4_K_M.gguf`, генерацию короткого и длинного ответа, отмену генерации и восстановление после перезапуска.
- Проверить Gemini API с ключом, затем fallback при отсутствии сети/квоты.
- Проверить локальный vision путь отдельно от текстовой генерации.
- Не очищать данные приложения и не удалять модели.

### 3. Голосовой режим «Джимми»

Предварительный кандидат для локального keyword spotting — sherpa-onnx. У него есть Android/Kotlin API и потоковый keyword spotter. Но доступные upstream KWS-модели из текущей документации ориентированы на английский и китайский; поддержку русского слова «Джимми» нельзя считать доказанной. Возможные прототипы: английское фонетическое представление `JIMMY` с проверкой на реальных русскоязычных записях или локальный русский ASR с ограниченной грамматикой.

До выбора модели:
- сравнить размер модели, CPU/RAM и задержку на Exynos 2200;
- проверить ложные срабатывания на обычной речи, телевизоре и музыке;
- проверить точность на разных расстояниях и голосах;
- хранить wake phrase отдельно от speaker profile;
- не использовать распознавание голоса как разрешение на удаление файлов, платежи или другие опасные действия.

Для непрерывного прослушивания потребуется отдельный microphone foreground service, явное разрешение пользователя, постоянное уведомление и обработка ограничений Android 16/Samsung battery management. Нельзя обещать гарантированную работу после принудительной остановки приложения или агрессивного энергосбережения.

Справка: https://k2-fsa.github.io/sherpa/onnx/kws/index.html
Android/Kotlin: https://k2-fsa.github.io/sherpa/onnx/android/index.html

### 4. Голосовой диалог

- После wake word включать распознавание команды.
- После завершения ответа ждать следующую реплику без повторения «Джимми».
- По таймауту тишины завершать диалог и возвращаться к wake-word режиму.
- Добавить явную кнопку/команду остановки микрофона.
- Подключить TTS и не допускать захвата собственного ответа микрофоном.

### 5. Инструменты и мультимодальность

- Подключить веб-поиск как отдельный облачный инструмент с источниками.
- Подключать Android-действия через allowlist, проверку разрешений и подтверждение опасных операций.
- Добавить явный переключатель для отправки выбранных пользователем изображений/файлов в облако; по умолчанию оставлять их локальными.
- Добавить проверку размера, MIME-типа и безопасную очистку временных файлов.

## Правила разработки

- GitLab main — единственный источник исходников.
- Любая функция: отдельная ветка → MR → проверка → merge → автоматическая синхронизация → CI.
- Не менять нативное ядро без подтверждённой необходимости.
- Не запускать Gradle на телефоне. Все тяжёлые сборки выполнять в GitHub Actions.
- Любой build report должен содержать точный SHA, версию, versionCode, размер и SHA-256.
- Не объявлять runtime-функцию готовой, пока она не проверена на устройстве.
