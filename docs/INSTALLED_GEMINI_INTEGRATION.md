# Интеграция с установленным Gemini

## Назначение

Добавить отдельный, явный способ использовать официальное Android-приложение Gemini, не смешивая его с уже существующим Gemini API.

## Что поддерживается

- Проверка Gemini API из настроек: короткий реальный `generateContent` запрос подтверждает не только сохранение ключа, но и доступность выбранной модели. Проверка запускается только по явному нажатию пользователя и не отправляет историю чата или вложения.

- Обнаружение пакета официального приложения `com.google.android.apps.bard`.
- Запуск Gemini через стандартную launcher activity.
- Передача выбранного текста через Android Sharesheet. Пользователь сам выбирает Gemini, если он доступен среди получателей.
- Существующий Gemini API остаётся отдельным облачным провайдером с ключом в Android Keystore.
- Локальный Qwen остаётся резервным провайдером.

## Ограничения Android

У стороннего приложения нет публичного документированного API, чтобы бесшумно отправлять запросы в приложение Gemini, управлять Gemini Live, получать поток ответа или встраивать его фоновую сессию. Sharesheet является действием пользователя; получатель самостоятельно решает, как обработать текст. Не использовать AccessibilityService для имитации нажатий или чтения интерфейса Gemini.

Для голосового пробуждения «Джимми» локальный аудиомодуль MOBILE AI AGENT должен оставаться владельцем микрофонной сессии. Этот мост открывает Gemini или передаёт выбранный текст, но не обещает бесшовный фоновый голосовой диалог внутри чужого приложения.

## Приватность

- Не передавать микрофон, вложения, фото, видео или историю чата без отдельного действия пользователя.
- Передавать только текст текущего запроса через системное меню «Поделиться».
- Запуск Gemini не считать завершённым ответом. Черновик и история MOBILE AI AGENT сохраняются.
- API-ключ, API-запросы и учётная запись установленного Gemini независимы друг от друга.

## Критерии приёмки

- Статус установки корректен.
- Кнопка запускает Gemini либо сообщает о недоступности.
- Передача открывает Sharesheet с точным текстом; до выбора получателя автоматической передачи нет.
- Gemini API и Qwen работают без изменений.
- Не используются AccessibilityService, UI scraping и недокументированные intent extras.
