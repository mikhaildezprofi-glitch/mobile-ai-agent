# План объединённой APK-сборки

Цель — не собирать APK после каждого изменения.

## Группа A: независимые runtime-данные

Промпты, модели, маршрутизация, UI-настройки, безопасные флаги модулей и команды хранятся в `runtime-config/`. После появления загрузчика эти изменения будут распространяться без APK.

## Группа B: накопительная разработка APK

Все изменения Kotlin/Compose, Android lifecycle, runtime-loader, локального кэша, проверки целостности, отката и интеграций собираются одной партией. Не запускать сборку для каждого отдельного коммита. Сначала завершить набор совместимых задач и выполнить статическую проверку, затем один MR и один build.

## Обязательные ворота перед релизом

- unit-тесты маршрутизации и конфигурации;
- проверка JSON и схем;
- проверка checksum и безопасного отката;
- сборка debug APK;
- извлечение signer SHA-256;
- сравнение сертификата с установленным приложением до установки;
- runtime-проверка JNI и модели на Samsung S23 FE.

## Ограничения

Не менять нативное ядро без причины. Не удалять пользовательские модели и данные. Не хранить signing key в Git. Не запускать Gradle на телефоне.
