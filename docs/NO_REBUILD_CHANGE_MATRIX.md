# Матрица изменений без пересборки APK

## Можно будет менять удалённо после внедрения runtime-загрузчика

| Изменение | Требуется APK |
|---|---|
| Системный промпт и профили промптов | Нет |
| Параметры генерации в допустимых пределах | Нет |
| Выбор уже встроенной модели/провайдера | Нет |
| Тексты и подсказки интерфейса, вынесенные в runtime config | Нет |
| Флаги существующих модулей | Нет |
| Маршрутизация между уже встроенными провайдерами | Нет |
| Справочник фраз команд для уже существующих действий | Нет |
| Ограничения размеров и количества вложений в поддерживаемом диапазоне | Нет |

## Всегда требуют APK

- Новые Kotlin/Java классы и исправления UI-логики.
- Новые Android permissions, services, receivers, activities и intent filters.
- Изменения Gradle, Compose, Android SDK/NDK и зависимостей.
- Новые сетевые клиенты и протоколы, если их нет в приложении.
- Новые инструменты, функции Android и обработчики действий.
- Изменения JNI, llama.cpp, ggml, OpenMP, ABI и нативных библиотек.
- Новые форматы файлов, алгоритмы, аудиодвижок, wake-word и TTS, если код ещё не встроен.

## Переходный этап

Сначала требуется один APK, который умеет безопасно загружать удалённый runtime bundle, проверять подписи/хеши и откатываться к последней рабочей версии. После этого большая часть будущих правок перечисленных в первой таблице будет распространяться через конфигурацию без APK.

Изменение только JSON/TXT в репозитории до внедрения такого клиента не изменит установленное приложение.
