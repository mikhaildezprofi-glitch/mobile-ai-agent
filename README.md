# MOBILE AI AGENT

Бесплатный Android AI-ассистент для локальной работы на устройстве с расширяемым гибридным режимом.

## Текущая версия: 0.3.8

### Реализовано

- Локальный inference через llama.cpp и GGUF-модели.
- Фоновая генерация через foreground service, уведомление о готовом ответе и восстановление чата.
- Единый `AgentCoordinator` для классификации задач и выбора доступного провайдера.
- Подключаемый Gemini cloud provider; API-ключ хранится в приватных настройках приложения, а не в исходниках.
- Чтение выбранных текстовых документов, PDF и поддерживаемых офисных файлов через безопасный локальный обработчик.
- Подготовка изображений для MTMD vision: ограничение размера, проверка количества и очистка временных файлов.
- JNI-интеграция vision projector для совместимых multimodal GGUF-моделей.
- Извлечение до четырёх равномерно распределённых кадров из выбранного видео для анализа через vision-модель.
- Мониторинг производительности устройства и диагностика ошибок.

### Работа с изображениями и видео

Для анализа изображений нужна совместимая vision-модель и соответствующий `mmproj`. Сам факт прикрепления файла не означает, что модель его увидела: если vision backend не готов, приложение сообщает об ограничении.

Видео не передаётся модели целиком. Приложение извлекает до четырёх кадров из ролика, уменьшает их до безопасного размера и передаёт как изображения. Поэтому вывод описывает только выбранные кадры, а не непрерывное движение или звук.

### Ограничения

- Реальный end-to-end анализ изображения и видео требует загрузки совместимой модели и projector. Компиляция JNI/backend сама по себе не подтверждает успешный анализ на устройстве.
- Видеозвук и полная покадровая обработка пока не реализованы.
- Файлы и вложения не отправляются в облачный провайдер автоматически.
- Действия Android должны проходить отдельную проверку разрешений и безопасности.
- При аварийном завершении сохраняется уже полученный текст, но нативная генерация не возобновляется с того же токена.

## Сборка APK

Требуются JDK 17, Android SDK и Gradle 8.13:

```bash
gradle --no-daemon :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
