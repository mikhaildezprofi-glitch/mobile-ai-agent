# MOBILE AI AGENT

**Текущая версия приложения: 0.3.9 (versionCode 21).**

Android AI-ассистент для Samsung S23 FE с локальной обработкой через llama.cpp/GGUF и гибридной маршрутизацией запросов в облако.

## Репозитории и сборка

- **Канонический репозиторий:** GitLab — https://gitlab.com/lenives777/mobile-ai-agent
- **Вторичная синхронизируемая копия:** GitHub — https://github.com/mikhaildezprofi-glitch/mobile-ai-agent
- **Основная CI-сборка и проверка:** GitLab CI/CD из `.gitlab-ci.yml`
- **Очередь задач агентов:** `agent-control/queue.json`
- **Правило:** изменения в отдельной ветке и Merge Request; прямые записи в `main` и автоматическое слияние запрещены.

GitHub Actions сохранены как платформенные workflow для вторичной копии. Источником истины для исходников и статуса задач остаётся GitLab.

## Реализованные компоненты приложения

- Локальный inference через llama.cpp и GGUF-модели.
- `AgentCoordinator` для выбора локального или облачного провайдера.
- Гибридный режим с Gemini для текстовых запросов, программирования и сложного анализа при наличии ключа и квоты.
- Локальный резервный режим при отсутствии сети, ключа или облачной квоты.
- Хранение ключа Gemini через Android Keystore.
- Выбранные пользователем документы и изображения не отправляются в облако автоматически.
- Чтение выбранных TXT, исходников, PDF и поддерживаемых офисных документов.
- Анализ изображений через llama.cpp `libmtmd` и совместимый vision projector.
- Встроенная загрузка SmolVLM 500M Q8_0 и projector с проверкой размера и SHA-256.
- Переключение Qwen3/SmolVLM: в RAM одновременно загружается только одна модель.
- Извлечение до четырёх кадров из выбранного видео.
- Фоновая генерация с уведомлением и монитор производительности устройства.
- Termux worker, безопасный allowlist команд, heartbeat и мониторинг.

## Модели

Модели не хранятся в Git, CI artifacts или GitLab repository.

| Модель | Назначение | Размер |
|---|---|---:|
| Qwen3-1.7B-Q4_K_M.gguf | Локальный текстовый режим | около 1.2 GB |
| SmolVLM-500M-Instruct-Q8_0.gguf | Анализ изображений | 436,806,912 bytes |
| mmproj-SmolVLM-500M-Instruct-Q8_0.gguf | Vision projector | 108,783,360 bytes |

Загрузчик сохраняет файлы в приватной папке приложения и проверяет SHA-256 перед использованием. Не добавляйте веса моделей в Git.

## Сборка и проверка

GitLab CI выполняет:
1. Проверку Python-скриптов и очереди задач.
2. Сборку debug APK на бесплатном shared runner.
3. Публикацию APK как job artifact.

Успешная сборка подтверждает компиляцию и создание APK, но не доказывает успешный запуск JNI, загрузку модели или inference. Эти этапы проверяются отдельно на Samsung S23 FE.

Среда сборки: JDK 17, Gradle 8.14.3, Android SDK 36, NDK 29.0.13113456, CMake 3.31.6; llama.cpp закреплён на commit `3de52ac38818978d6da8f386eda43a856e53714a`.

## Известные ограничения

- На устройстве ранее возникала ошибка JNI `__kmpc_global_thread_num`; окончательное исправление считается подтверждённым только после установки новой сборки и успешного inference.
- Видеозвук и непрерывный анализ всего ролика не реализованы.
- Управление Android требует отдельных разрешений и явного подтверждения пользователя.
- Поиск в интернете внутри приложения пока не подключён.

## Безопасность и правила

- Не хранить в репозитории API keys, токены, приватные ключи подписи, APK, GGUF-модели и пользовательские резервные копии.
- Не изменять `main` напрямую.
- Не выполнять destructive cleanup без проверки контрольных сумм и резервных копий.
- Одна агентная задача за раз; следующая запускается после критериев приёмки текущей.
