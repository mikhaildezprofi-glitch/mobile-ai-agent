# MOBILE AI AGENT

**Текущая версия исходников приложения: 0.4.1 (versionCode 23).**

Android-ассистент с локальным inference через PocketPal llama.rn/GGUF, гибридным облачным режимом, обработкой выбранных документов и изображений.

## Репозитории и сборка

- Основной репозиторий проекта: [GitLab](https://gitlab.com/lenives777/mobile-ai-agent).
- Синхронизируемая копия и облачная APK-сборка: [GitHub](https://github.com/mikhaildezprofi-glitch/mobile-ai-agent).
- Во время текущей разработки используется единая ветка `integration/agent-consolidated-20261119`.
- APK workflow намеренно не запускается на этой ветке. Финальная сборка будет выполнена после завершения интеграции и проверок.
- Для промежуточных проверок используется отдельный workflow unit-тестов; нативный workflow собирает только ARM64 .so библиотеки.

## Основные компоненты

- Локальная текстовая генерация через PocketPal llama.rn, GGUF и CPU backend.
- JNI/Kotlin мост с Jinja chat templates и структурированными function calls.
- Allow-list локальных инструментов и последовательный runner с лимитом вызовов.
- Гибридный выбор локального и облачного провайдера Gemini.
- Хранение API-ключа через Android Keystore.
- Отдельное зашифрованное хранилище GitHub fine-grained PAT через Android Keystore (AES-256/GCM); токен не отображается после сохранения и не смешивается с Gemini credentials.
- Планировщик задач, SQLite-журнал результатов и возобновление незавершённых шагов.
- Обработка выбранных пользователем документов и изображений.
- Vision projector и модель SmolVLM для анализа изображений.
- Извлечение кадров из видео.
- Фоновая генерация и монитор производительности устройства.

PocketPal native core фиксируется на commit `ae0e55b7dacdb06d37843273204a3e7ff294a6a2`. Для Samsung S23 FE Exynos используется generic ARM64 CPU вариант; Qualcomm-only backends не включаются.

PocketPal используется для текстового и Vision/MTMD inference. Общий локальный provider держит только один GGUF-контекст: переключается между Qwen и SmolVLM+mmproj, выгружая предыдущую модель. Старый llama.cpp Android-модуль исключён из Gradle и CI; исходная ссылка оставлена как неиспользуемый rollback snapshot.

## Code Agent

Добавлен начальный локальный Code Agent с пятью структурированными инструментами: просмотр файлов, чтение исходников, текстовый поиск, точечная замена уникального фрагмента и создание/изменение файлов в приватной рабочей области `filesDir/code-workspace`. Изменение существующего файла требует совпадения SHA-256, пути ограничены корнем рабочей области, записи атомарны. Произвольный shell и выполнение кода не включены. Импорт/экспорт ZIP-проектов через системный выбор файлов и выбор активной рабочей области добавлены. GitHub Actions executor, Git операции и UI подтверждения изменений остаются следующими этапами. Подробности: [docs/CODE_AGENT.md](docs/CODE_AGENT.md).

## Модели

Веса моделей не хранятся в Git или CI artifacts. Они устанавливаются в приватную папку приложения и проверяются по SHA-256.

- Qwen3-1.7B-Q4_K_M: локальный текстовый режим через PocketPal.
- SmolVLM-500M-Instruct-Q8_0 и совместимый mmproj: локальный Vision/MTMD через тот же PocketPal JNI bridge.

## Проверки

GitHub Actions использует JDK 17, Gradle 8.14.3, Android SDK 36, NDK 29.0.13113456 и CMake 3.31.6.

Успешная сборка ARM64 .so подтверждает компиляцию нативного ядра и JNI-моста, но не загрузку GGUF и работу inference на телефоне. Проверка на Samsung Exynos ещё обязательна. APK пока не собирался для этой интеграционной ветки.

## Известные ограничения

- Структурированные вызовы инструментов поддерживают только локальные `calculate` и `datetime`.
- Непрерывный анализ видео и видеозвука не реализован.
- Поиск в интернете и Android-действия требуют отдельных безопасных исполнителей и подтверждения пользователя.
- Реальная скорость, память, температура, переключение Qwen/SmolVLM и стабильность PocketPal на Exynos должны быть проверены на устройстве. APK пока не собирался.

## Безопасность

Не добавляйте в Git API-ключи, токены, signing keys, APK, GGUF-модели, приватные логи и пользовательские резервные копии. Не очищайте данные приложения при обновлении APK.
