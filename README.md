# MOBILE AI AGENT

**Текущая версия исходников приложения: 0.3.9 (versionCode 21).**

Android-ассистент с локальным inference через llama.cpp/GGUF, гибридным облачным режимом, обработкой выбранных документов и изображений.

## Репозитории и сборка

- Основной репозиторий: [GitLab](https://gitlab.com/lenives777/mobile-ai-agent)
- Синхронизируемая копия и APK-сборка: [GitHub](https://github.com/mikhaildezprofi-glitch/mobile-ai-agent)
- Android APK собирается workflow **Android APK Build** в GitHub Actions.
- GitLab проверяет опубликованный APK только для синхронизированных веток `sync/*`, сверяя исходный SHA и SHA-256.
- Изменения вносятся в отдельные ветки и проходят Merge Request. Прямые изменения в защищённый `main` не используются.

## Основные компоненты

- Локальная генерация через llama.cpp и GGUF.
- Гибридный выбор локального и облачного провайдера.
- Хранение API-ключа через Android Keystore.
- Обработка выбранных пользователем документов и изображений.
- Vision projector и модель SmolVLM для анализа изображений.
- Извлечение кадров из видео.
- Фоновая генерация и монитор производительности устройства.
- Termux monitor для состояния сборки, Wi-Fi, ADB, RAM и температуры.

Компоненты `AgentCoordinator` и `AgentToolRegistry` относятся к функциям самого Android-приложения. Они не запускают внешних разработческих агентов и сохранены.

## Модели

Веса моделей не хранятся в Git или CI artifacts. Они устанавливаются в приватную папку приложения и проверяются по SHA-256.

- Qwen3-1.7B-Q4_K_M: локальный текстовый режим.
- SmolVLM-500M-Instruct-Q8_0 и совместимый mmproj: анализ изображений.

## Сборка и проверка

GitHub Actions использует JDK 17, Gradle 8.14.3, Android SDK 36, NDK 29.0.13113456 и CMake 3.31.6. llama.cpp фиксируется на commit `3de52ac38818978d6da8f386eda43a856e53714a`.

Успешная сборка APK не подтверждает работу JNI, загрузку моделей или inference. Эти проверки выполняются отдельно на устройстве.

## Известные ограничения

- Ранее на Samsung S23 FE возникала JNI-ошибка `__kmpc_global_thread_num`. Считать её исправленной можно только после фактического запуска модели.
- Полноценный непрерывный анализ видео и видеозвука не реализован.
- Действия Android требуют соответствующих разрешений и подтверждения пользователя.

## Безопасность

Не добавляйте в Git API-ключи, токены, signing keys, APK, GGUF-модели, приватные логи и пользовательские резервные копии. Не очищайте данные приложения при обновлении APK.
